# SR Performance Tracker

A simple phone-friendly page for grading the 21 selected Section Representatives (KSELC).

- Tap 1–5 under a name to grade. Tap the same number again to clear it.
- Tap a name to add notes or remove them.
- Search, filter (Unrated / Top / Needs work) and add extra people.
- "Results (copy or email)" at the bottom lists everyone's grade and notes.
- Grades are saved in your own browser on your own device. Nothing is sent anywhere.

## Put it online with GitHub Pages

1. Create a new public repository on GitHub.
2. Upload `index.html` and `README.md` to it.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
5. After a minute your link appears: `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

Open the link in Safari or Chrome. File previews (like Quick Look on iPad) do not run JavaScript, so the buttons will not work there.
